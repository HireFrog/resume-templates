# Resume Templates

50 free, role-specific resume templates, organized into 7 categories. Each template includes a recommended section structure, key competencies for that role, an example bullet-point framework, a fill-in-the-blank skeleton, and role-specific tips.

Pick the closest match to your target role — it's fine if the title isn't a perfect match. The structure and advice will still transfer.
