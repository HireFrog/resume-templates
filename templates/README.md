# Resume Templates

50 free, role-specific resume templates as plain Markdown (`.md`) source files, organized into 7 categories. Each one includes a recommended section structure, key competencies for that role, an example bullet-point framework, a fill-in-the-blank skeleton, and role-specific tips — ready to edit by hand or hand to an AI agent.

Pick the closest match to your target role — it's fine if the title isn't a perfect match. The structure and advice will still transfer.
