# UI Designer Resume Template

*For designers focused on visual systems, interaction detail, and polish within an established product.*

UI-focused roles are judged heavily on visual execution and consistency — typography, spacing, color, and interaction detail applied within a system rather than invented from scratch each time. This template still frames your work around decisions and impact rather than pure aesthetics, because that's what differentiates a strong resume even in a visually-driven discipline. It also gives design system and craft consistency their own space, since that's often the real signal at this level.

## Resume Structure

1. **Header** — name, contact, portfolio link (essential for this role).
2. **Summary** — your visual/craft focus (e.g. design systems, marketing sites, mobile UI).
3. **Skills** — tools, systems, and visual disciplines.
4. **Experience** — reverse-chronological, framed around what you built and its effect.
5. **Selected Projects** — case studies with links.
6. **Education** — degree and institution; keep it short, since visual craft is judged in the portfolio, not on paper.
7. **Certifications** *(optional)* — relevant tool or accessibility certifications only.

## Key Competency Areas

- Visual design craft: typography, layout, color, and hierarchy
- Building and maintaining design systems and component libraries
- Interaction and micro-interaction design (states, transitions, motion)
- Consistency across platforms (web, iOS, Android)
- High-fidelity execution within an existing design language, not just concepting
- Collaborating with engineers on implementation fidelity
- Adapting visual language to brand and product constraints
- Catching and fixing visual inconsistencies before they ship
- Maintaining accessibility standards (contrast, type scale, tap targets) within the visual system
- Iterating quickly on high-fidelity comps based on design review feedback

## Bullet Point Framework

Structure each bullet as **action + what you built or refined + measurable or qualitative outcome**. Since UI work often lives inside an existing system, name the scope precisely (how many screens, components, or platforms) and tie it to a concrete effect — speed, consistency, or a metric — rather than describing the visual result alone.

- Built a [N]-component design system used across [N] product surfaces, cutting design-to-dev handoff time by [X%]
- Redesigned [product/marketing surface] visual language, improving [metric, e.g. conversion, engagement] by [X%]
- Standardized [pattern] across [N] platforms, eliminating inconsistencies flagged in [N] design reviews
- Partnered with engineering to achieve pixel-accurate implementation of [feature], reducing QA visual bugs by [X%]
- Designed [N] high-fidelity screens for [feature launch], shipped on [timeline]
- Defined interaction and motion specs for [component/flow], adopted as the team standard across [N] surfaces
- Audited and unified [N] inconsistent UI patterns into a single component, reducing visual QA bugs by [X%]
- Refined [component/pattern] states and micro-interactions, improving perceived responsiveness in user feedback

## Tips for UI Designer Resumes

- Pair every visual accomplishment with why it mattered (consistency, speed, conversion) — not just what it looked like.
- Mention design system work explicitly; it signals you think beyond a single screen.
- Reference collaboration with engineering — implementation fidelity is part of the job.
- Keep the portfolio current and linked prominently; it will be checked before the resume is finished being read.
- Show precision at the detail level (states, spacing, motion) somewhere — it's what separates UI craft from general design.
- Avoid subjective adjectives ("beautiful," "sleek") — let the portfolio and outcomes speak for themselves.
- If you work across platforms (web, iOS, Android), call out consistency work explicitly — it's a distinct, valued skill.
