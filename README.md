## Why `.md`?

Every template here is plain-text Markdown, not a `.docx` or `.pdf`. That's a deliberate choice:

- **Plain text** — no proprietary format, no version lock-in, opens anywhere.
- **Human-readable** — skim it in a browser, an editor, or a phone, with no special software.
- **AI-agent-readable** — clean, predictable structure that's easy for an AI assistant to parse and work with.
- **Easy to copy and modify** — no fighting with document formatting to change a line.
- **Git-friendly** — track changes, diff versions, branch a resume per application.
- **Portable** — paste it into any editor, static site, or tool that reads text.

That combination makes these files useful as structured source material if you use AI coding or agent tools — Claude Code, Codex, Cursor, GitHub Copilot, or similar — as well as by hand. Markdown itself doesn't add any AI capability; it just gives an agent clean, portable context to read and work with.

## How to use a template

1. Open the `.md` file closest to your target role.
2. Copy the skeleton in the `## Template` section into your editor of choice — or hand the whole file to an AI agent along with your experience and the job description.
3. Fill in your real experience using the bullet-point framework as a guide — swap every bracketed placeholder for something true and specific.
4. Read the `## Tips` section for what actually matters for that role.

That gets you a solid, generic resume. The next step is making it not generic.
