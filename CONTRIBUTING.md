# Contributing

Thanks for considering a contribution to HireFrog Resume Templates. This is a small, focused repository — the goal is to keep every template genuinely useful, not to grow it into a framework.

## What's welcome

- **New role templates** for roles not yet covered, following the existing structure and file naming (`templates/<category>/<role-slug>.md`).
- **Improvements to existing templates** — better example bullets, clearer structure, fixes to outdated advice.
- **Corrections** to the job-search guides in `job-search/`.
- **Typo and formatting fixes**.

## What's out of scope

This repository is intentionally limited to static Markdown content. Please don't submit:

- Application code, scripts, or tooling of any kind
- Resume-generation, job-matching, or job-search automation logic
- Anything that depends on an external API or service

If you're interested in that kind of functionality, that's what [HireFrog](https://www.hirefrog.co) is for — it's a separate product, not part of this repository.

## Template format

Each resume template follows the same structure: an intro, a recommended resume structure, key competency areas, a bullet-point framework with examples, a fill-in-the-blank template, role-specific tips, and a single closing note pointing to HireFrog. Please match this structure so the repository stays consistent. Look at an existing file in the same category before adding a new one.

## Submitting a change

1. Fork the repository and create a branch for your change.
2. Keep pull requests focused — one template or one guide per PR is easiest to review.
3. Open a pull request describing what you changed and why.

## Questions

Open an issue if you're not sure whether something fits before putting in the work.
